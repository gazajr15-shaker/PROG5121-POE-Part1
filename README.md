# PROG5121 POE Part 1

## Registration and Login System

This project is a Java application developed for the PROG5121 Programming 1 POE.

The application focuses on user registration and login functionality.

## Features

- User registration
- Username validation
- Password complexity validation
- South African cellphone number validation
- User login validation
- Login success and failure messages

## Technologies Used

- Java
- Apache NetBeans
- Maven
- GitHub

## Project Structure

The project source code is located in:

`src/main/java`

The Maven configuration is contained in:

`pom.xml`

## How to Run

1. Clone or download this repository.
2. Open the project in Apache NetBeans.
3. Allow Maven dependencies to load.
4. Run the `Main.java` class.
5. Follow the instructions displayed by the application.
